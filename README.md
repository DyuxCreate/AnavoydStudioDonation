# Anavoyd Studio

> Official website for Anavoyd Studio, created to bring the studio closer to its community and supporters.

## Overview

The Anavoyd Studio website is a space designed to connect the studio with its community.

More than simply supporting the project through donations, users can become part of the development journey, follow the project's progress, discover news and connect with the community through Discord.

## Features

- Studio information
- Project presentation
- News and updates
- Community access through Discord
- Donation/support system
- Team information
- Direct connection between the project and its supporters

## Technologies

- HTML5
- CSS3
- JavaScript

## Project Status

The project is continuously being improved and expanded.
